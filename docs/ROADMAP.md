# Roadmap

- [x] Add plant records
- [x] Add a photo

- Filters: native, sun, wildlife value, status
- Nursery/source and price
- Propagation notes
- Flowering dates
- Garden locations / beds
- Bird observations
- Garden ideas
- Sync between devices

These are possibilities, not commitments.
