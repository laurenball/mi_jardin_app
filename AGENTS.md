# Repository instructions

- Commit completed changes locally at the end of every task.
- Never push commits to a remote. Do not run `git push`; the user handles publishing.
- Stage only files related to the task, and leave unrelated worktree changes alone.
- This app is for internal use. Choose plant and fruit photos for identification value and visual quality, without limiting the search to freely licensed images. Record the source and credited photographer when available.
